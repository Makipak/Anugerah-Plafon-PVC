# 03. Keyword Map

> Semua keyword disusun dari analisis intent dan hasil SERP. **Volume belum ada.** Isi kolom Volume dari Google Keyword Planner (lokasi: Banten) dan perbarui dengan data Search Console setelah live.

## Cara membaca

- **Tier 1:** transaksional lokal, konversi tertinggi, dikerjakan pertama.
- **Tier 2:** produk dan layanan turunan.
- **Tier 3:** informasional (blog), traffic jangka panjang.
- Satu halaman, satu keyword utama. Jangan membuat dua halaman untuk intent yang sama.

## Pemetaan cepat: keyword ke tag

| Elemen | Aturan |
|---|---|
| Title | Keyword utama + kota + brand, maks ~60 karakter total. Template menambah 22 karakter (" \| Anugrah Plafon PVC"), jadi judul halaman maks ~38 karakter. Artikel blog memakai judul tanpa template |
| Meta description | 140-160 karakter, ada manfaat + CTA |
| H1 | Satu per halaman, memuat keyword utama secara natural |
| H2/H3 | Variasi dan pertanyaan terkait |
| URL | Slug pendek berisi keyword |
| Alt gambar | Deskripsi nyata (jenis plafon, ruang, lokasi) |

## Template title

| Halaman | Contoh |
|---|---|
| Home | `Plafon PVC Serang - Toko & Jasa Pasang \| Anugrah Plafon PVC` |
| Layanan | `Jasa Pasang Plafon PVC Serang \| Anugrah Plafon PVC` |
| Harga | `Harga Jasa Pasang Plafon PVC per Meter \| Anugrah Plafon PVC` |
| Area | `Jasa Plafon PVC Cilegon \| Anugrah Plafon PVC` |

Jangan menulis "garansi" atau "termurah" di halaman kecuali benar dan dapat dibuktikan.

## Rencana validasi

1. Isi volume dari Keyword Planner.
2. Cek SERP manual dari Serang (incognito) tiap keyword Tier 1 dan catat 5 teratas.
3. Setelah live: tarik query asli dari Search Console tiap bulan dan pindahkan keyword yang muncul ke peta ini.
